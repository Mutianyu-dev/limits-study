# 四周 C 语言冲刺计划（大一 · 已学函数）

目标：面试时能独立写出「菱形 / 回文 / 素数 / 简单统计」这类题，并能讲清 C 项目里每一行。
每天 1.5–2 小时，周末各留一次复盘。

## 第 1 周：循环与图形（把 for 练到不用想）

| 天 | 练习 | 验收 |
|---|---|---|
| 1 | 打印 1–100，跳过 3 的倍数 | 不用看笔记 |
| 2 | 九九乘法表（下三角） | 两层循环，边界正确 |
| 3 | 打印直角三角形、倒三角形 | 行数与空格关系说得出 |
| 4 | 打印实心菱形（n 为奇数） | 15 分钟内白纸写完 |
| 5 | 空心菱形 / 沙漏 | 只改内层判断 |
| 6 | 判断素数（试除到平方根） | 说出为什么到 sqrt 就够 |
| 7 | 复盘：把菱形默写一遍 | 不看任何资料 |

## 第 2 周：函数与递归（把逻辑拆小）

| 天 | 练习 | 验收 |
|---|---|---|
| 1 | 阶乘（循环版 + 递归版） | 说出递归终止条件 |
| 2 | 斐波那契（循环版，别用递归） | 说出为什么循环更快 |
| 3 | 最大公约数（辗转相除） | 手推一遍 48 与 18 |
| 4 | 数字反转，判断回文数 | 不转字符串也能判 |
| 5 | 把第 1 周的图形题改成函数 | 参数、返回值清楚 |
| 6 | 简易菜单程序（switch + 循环） | 输入 0 才退出 |
| 7 | 复盘：把训练器菜单部分自己写一遍 | 与样稿对比差异 |

## 第 3 周：数组与字符串（面试要求里必须补）

| 天 | 练习 | 验收 |
|---|---|---|
| 1 | 一维数组：求和、最大值、逆序 | 下标边界不出错 |
| 2 | 冒泡排序 | 说出两层循环各管什么 |
| 3 | 二分查找（有序数组） | 说出 mid 与边界更新 |
| 4 | 字符数组：strlen 手写版 | 不调用库函数 |
| 5 | 判断字符串回文 | 双指针相向走 |
| 6 | 统计单词数 / 字符出现次数 | 能处理空格 |
| 7 | 复盘：把训练器改成「题库数组」版 | 体会数组的价值 |

## 第 4 周：指针入门 + 项目重写 + 模拟面试

| 天 | 练习 | 验收 |
|---|---|---|
| 1 | 指针与地址：交换两个数 | 说清 `*` 与 `&` |
| 2 | 数组与指针的关系 | 能解释 `a[i]` 与 `*(a+i)` |
| 3 | 重写训练器：函数拆分 + 注释 | 不看样稿 |
| 4 | 给训练器加一个新题型 | 自己设计、自己测 |
| 5 | 模拟面试：菱形 + 回文 + 素数 | 各 10 分钟 |
| 6 | 讲项目：30 秒版 + 追问 | 录音回听 |
| 7 | 总复盘：整理错题本 | 列出仍不熟的 5 个点 |

## 经典题清单（面试高频）

1. 打印菱形 / 空心菱形 / 沙漏
2. 判断回文数、回文字符串
3. 素数判定、100 以内素数
4. 最大公约数、最小公倍数
5. 斐波那契（循环）
6. 冒泡排序、选择排序
7. 二分查找
8. 数组逆序、最大值、次大值
9. 统计字符、单词数
10. 九九乘法表、杨辉三角（数组）

## 面试前自检

- 能在 15 分钟内白纸写出菱形，并解释每一行；
- 能说清 `scanf` 返回值、`getchar` 清缓冲；
- 能说清浮点为什么不能直接用 `==`；
- 能讲出训练器的函数划分，以及你改过哪两处；
- 数组、指针至少能读懂，不要求熟练。
