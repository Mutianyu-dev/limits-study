# 极限研习 · C 命令行训练器

一个刻意做小的 C 项目：**只用变量、分支、循环、函数**，不碰数组、指针、结构体。
它和「极限研习」网站是同一套内容逻辑（题库判分 + 连对奖励），只是把界面换成了控制台。

## 为什么选这个项目

- 你目前学到函数，这个项目用到的语法全部在「函数 + 循环 + 分支」范围内；
- 面试考核里的「打印菱形」「判断回文」这类题，它直接覆盖了图形部分；
- 它能现场演示：输入 7，菱形立刻出来；输入答案，判分和诗句立刻出来；
- 代码量约 250 行，可以在一周内逐行吃透，而不是抄一个看不懂的大项目。

## 编译与运行

```bash
gcc -std=c99 -Wall -Wextra -o limits_trainer limits_trainer.c
./limits_trainer
```

Windows + Dev-C++：新建 Console Application，把 `limits_trainer.c` 内容粘进去，直接编译运行。
如果中文显示乱码，把源文件另存为 UTF-8；`main` 里的 `chcp 65001` 是为此准备的。

## 关键点与思考过程

1. **先拆功能，再写代码。**
   菜单只负责分发，每个功能一个函数。这样每个函数都能单独测试：先让菱形跑通，再做判分，最后接菜单。

2. **输入必须校验。**
   `scanf("%d", &value)` 的返回值是「成功读到了几个」，不是输入的数。用户输入字母时返回 0，所以要清空缓冲区并重问。这是面试官很爱追问的一点。

3. **菱形的空格公式。**
   上半部分第 `i` 行（`i = 1,3,5…n`）：空格 `(n - i) / 2` 个，星号 `i` 个。
   下半部分从 `n - 2` 开始倒着走，公式不变。先写上半、再写下半，比一次写完更不容易错。

4. **连对是一个状态机。**
   `streak` 答对加一、答错清零；`streak % 3 == 0` 时奖励。状态变量放在 `play_limits` 里，不要用全局变量。

5. **浮点判分不能写 `==`。**
   答案是 `k*k/2.0`，用户可能输入 `4.5`。用「差的绝对值 < 0.000001」判断，避免 `4.499999` 被判错。

6. **随机数只播种一次。**
   `srand(time(NULL))` 放在 `main` 开头；放进循环里会得到同一串随机数。

## 你可以自己改的地方（面试时讲“我改过”）

1. 把 5 题改成 10 题，正确率按百分比输出；
2. 增加一种题型：`lim (1-cos(kx))/x^2` 已有，试试加 `lim (e^(kx)-1-kx)/x^2 = k^2/2`；
3. 把实心菱形改成空心菱形（只打印边界星号）；
4. 奖励诗句换一批，或按连对次数切换「大爱仙尊 / 教员」两种口吻；
5. 记录「历史最佳连对」，退出时打印；
6. 加一个「错题重做」：不学数组也能做——把错题的 `k` 和题型用两个变量记下来，重做一次。

## 面试 30 秒讲法

> 这是我写的一个 C 控制台小项目，主题和我的极限学习网站一致。
> 它用函数把菜单、输入校验、出题判分、图形打印拆开；连对三题会触发诗句奖励。
> 我在里面重点处理了两件事：一是 `scanf` 的输入校验，二是菱形打印的行数与空格公式。
> 代码没有用数组和指针，是我目前语法范围内能完全讲清楚的一个完整程序。

追问预案：

- 为什么 `scanf` 要用返回值？→ 输入非法时它会失败，必须清缓冲重问。
- 菱形为什么要分上下两部分？→ 上半行数递增、下半递减，边界用 `n-2` 起跳最稳。
- 浮点为什么不用 `==`？→ 二进制表示有误差，用容差比较。
- 连对怎么实现的？→ 一个整型状态变量，答对 `++`、答错归零。
