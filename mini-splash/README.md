# 启动页 · 网站真实代码（不是简化版）

这个目录里的文件，是从「极限研习」网站 `public/` 里**原样复制**出来的启动页：

| 文件 | 来源 | 改动 |
|---|---|---|
| `index.html` | `public/index.html` | 只把 `/assets/...` 改成相对路径，去掉用不到的 math/core 脚本 |
| `assets/app.css` | `public/assets/app.css` | 一字未改（全站样式） |

所以它和你在网站上看到的启动页是**同一份代码、同一套样式**，不是照着做的仿制品。

## 运行

- 直接双击 `index.html`：能看启动页、动画、八个词
- 点任意词或 Math 菱形：会跳到正在运行的网站主界面（需要网站服务开着）

## 为什么之前看着不一样

上一版 `mini-splash` 是我为了“零依赖”重写的简化版：字号、间距、背景网格、字体栈都和网站不同，所以你一对比就觉得不对。那一版已经删掉，换成了现在这份真实代码。

## 你要“当作自己敲的”，最少要搞懂这三段

1. **八个词的数据**：`WORDS` 数组，每个词有 `angle`、`radius`、`big`
2. **摆位置的两行**：
   ```js
   const rad = (word.angle * Math.PI) / 180;
   const x = 50 + word.radius * Math.cos(rad);
   const y = 50 + word.radius * Math.sin(rad);
   ```
   角度换弧度，再用 cos/sin 把半径投到横纵坐标；`50` 是舞台中心。
3. **点击后的过渡**：加 `leaving` 类，等 460ms 再跳转；以及 `button.dataset.index` 记录是第几个词。

CSS 里对应的是 `.splash`、`.orbit`、`.mark`、`.word` 四块，重点是 `.mark` 的 `rotate(45deg)` 和 `.word` 的 `translate(-50%, -50%)`。

## 面试讲法（30 秒）

> 这是项目启动页，八个词不是写死的坐标，而是存成角度和半径的数据，用循环和三角函数算出来；
> 中心菱形旋转 45 度，词用 translate(-50%,-50%) 以自身中心对齐坐标；
> 点击时先加过渡类，再延迟跳转，避免生硬切换。

## 一句实话

代码是现成的，但**“敲出来”和“能讲清楚”是两件事**。面试官会问“为什么用百分比”“为什么 translate 负一半”“循环里怎么知道点的哪个词”。
建议把 `splash.js` 关掉注释、照着重写三遍，再改两处（加第 9 个词、换半径），能白纸画出坐标推导，再说是自己写的也不迟。
